Pilih Jalur Belajar Software Development

Tersedia dua track kurikulum praktikum lengkap: dari pembuatan backend web dan REST API menggunakan PHP/Laravel, hingga pengembangan aplikasi mobile native menggunakan React Native & Expo.

Pilih Jalur Lihat Roadmap 10 Minggu
WEB TRACK 10 Pertemuan

Web Development

PHP Native • MySQL • Laragon • OOP MVC • Laravel 11 • REST API

Kuasai fundamental pembuatan aplikasi web dari sisi server. Dimulai dari dasar sintaks PHP native, form handling, integrasi basis data MySQL di Laragon, arsitektur OOP & MVC, hingga membangun REST API menggunakan Laravel yang siap dikonsumsi oleh aplikasi mobile.

Topik Kunci:
Minggu 1: Setup Laragon & Dasar PHP Minggu 2: Form Handling & Database Minggu 3: CRUD PHP & MySQL Minggu 4: OOP & MVC Dasar Minggu 5: Pengenalan Laravel Minggu 7: REST API Laravel
Buka Silabus Web Development
MOBILE TRACK 10 Pertemuan

Mobile Development

React Native • Expo Go • TypeScript • State • API Client • Build APK

Bangun aplikasi mobile native modern yang responsif dan interaktif. Pelajari styling dengan StyleSheet, state management dengan React Hooks, integrasi Expo Go di smartphone fisik, konsumsi REST API Laravel, hingga proses export/build file APK Android menggunakan EAS Build.

Topik Kunci:
Minggu 1: Setup Expo & TypeScript Minggu 2: UI, State & Interaction Minggu 3: Navigation Expo Router Minggu 5: CRUD & Local Storage Minggu 6: Consume Laravel REST API Minggu 10: Finalisasi & Build APK
Buka Silabus Mobile Development
