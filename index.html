Web Development

Mobile Development

Topik Kunci:
Minggu 1: Setup Expo & TypeScript Minggu 2: UI, State & Interaction Minggu 3: Navigation Expo Router Minggu 5: CRUD & Local Storage Minggu 6: Consume Laravel REST API Minggu 10: Finalisasi & Build APK

Profil Spesialisasi Karir

Frontend Web Developer

Bertanggung jawab membangun antarmuka web (UI) yang interaktif, responsif terhadap semua ukuran perangkat, aksesibel (A11y), cepat, dan mudah dipindai mesin pencari (SEO). Mengubah desain grafis menjadi kode nyata dan mengonsumsi data asinkron dari REST API.

Teknologi & Toolkit Kunci:
HTML5 Semantik CSS3 Flexbox/Grid Bootstrap 5.3 JavaScript ES6+ Fetch API & JSON Git & GitHub
Fokus: Client-Side Interface & REST API Integration
01
FASE 1 • FONDASI WEB & STRUKTUR DOKUMEN

Fondasi Internet & HTML5 Semantik

Estimasi: 1–2 Minggu
Mengapa Topik Ini Penting?
Sebelum menyusun styling atau logika interaktif, developer wajib memahami cara browser berkomunikasi dengan server lewat protokol HTTP, serta menyusun dokumen secara semantik. Struktur HTML5 yang benar memastikan website ramah mesin pencari (SEO), aksesibel bagi pembaca layar difabel (A11y), dan stabil saat dimanipulasi JavaScript.
Topik & Keterampilan Kunci:
Cara Kerja DNS, IP & HTTP/HTTPS Tag & Dokumen HTML5 Semantik Form Input & Validasi Native HTML5 Media & Gambar Responsif Web Accessibility (A11y) & ARIA SEO-Friendly Metadata
Milestone Proyek Mandiri: Membuat halaman profil curriculum vitae semantik lengkap dengan form kontak ber-validasi native murni HTML5 tanpa JavaScript.
Pelajari Langsung: W3Schools HTML5 Tutorial W3Schools HTML Forms MDN Panduan HTML roadmap.sh/frontend #HTML
02
FASE 2 • STYLING MODERN & RESPONSIVE LAYOUT

Modern Styling & Responsive Web Design

Estimasi: 2–3 Minggu
Mengapa Topik Ini Penting?
Pengguna mengakses web dari berbagai perangkat mulai dari ponsel saku hingga layar 4K. Menguasai CSS Box Model, Flexbox (1 Dimensi), dan CSS Grid (2 Dimensi) membuat tata letak luwes. Dipadukan dengan Bootstrap 5, kamu dapat membangun UI berstandar industri dengan kecepatan tinggi menggunakan sistem grid 12-kolom dan komponen siap pakai.
Topik & Keterampilan Kunci:
CSS Box Model (Margin, Padding, Border) CSS Flexbox (Main & Cross Axis, Justify) CSS Grid (Grid Template, Areas & Gap) Mobile-First Approach & Media Queries Variabel CSS & Pseudo-classes (:hover, :focus) Bootstrap 5 (Grid, Navbar, Cards, Utilities)
Milestone Proyek Mandiri: Membangun Landing Page produk digital responsif menggunakan Bootstrap 5 dan tema dark/light mode harmonis.
Pelajari Langsung: W3Schools CSS3 Tutorial W3Schools Bootstrap 5 MDN Panduan CSS Dokumentasi Bootstrap 5.3
03
FASE 3 • LOGIKA PEMROGRAMAN & INTERAKTIVITAS

Pemrograman JavaScript Modern (ES6+)

Estimasi: 3–4 Minggu
Mengapa Topik Ini Penting?
JavaScript adalah mesin penggerak web modern. Tanpanya, halaman web hanyalah dokumen statis. Mempelajari JavaScript membekali developer kemampuan memanipulasi elemen HTML dan style CSS secara real-time via DOM, merespons klik dan input form dengan event listeners, serta mengolah koleksi data array method sebelum melangkah ke integrasi API.
Topik & Keterampilan Kunci:
Variabel (let, const), Tipe Data & Logika Percabangan Arrow Functions & Scoping ES6 Array Methods (map, filter, find, reduce) Manipulasi DOM (querySelector, classList, innerHTML) Event Handling (click, submit, keyup, change) Asynchronous JS (Promises & Async/Await)
Milestone Proyek Mandiri: Membangun Aplikasi To-Do List Interaktif lengkap dengan pencarian teks cepat, filter status tugas, dan penghitung ringkasan tugas aktif.
Pelajari Langsung: W3Schools JavaScript Tutorial W3Schools HTML DOM MDN Panduan JavaScript roadmap.sh/javascript
04
FASE 4 • KONTROL VERSI & DEVELOPER TOOLING

Version Control (Git/GitHub) & Modern Tooling

Estimasi: 1–2 Minggu
Mengapa Topik Ini Penting?
Di dunia kerja, developer tidak pernah bekerja tanpa jejak riwayat atau bekerja secara soliter. Git memungkinkan pelacakan tiap baris perubahan kode, bereksperimen di cabang (branching) tanpa merusak kode utama, dan berkolaborasi di GitHub. Menguasai Node.js & NPM juga mengenalkan ekosistem library modern.
Topik & Keterampilan Kunci:
Git CLI (git init, add, commit, push, pull, log) Branching, Merging & Conflict Resolution GitHub Remote, Pull Request & Code Review Pengenalan Node.js, NPM & package.json Struktur Folder Proyek Web Modular Deploy Gratis via GitHub Pages & Vercel
Milestone Proyek Mandiri: Mempublikasikan repository portofolio frontend ke GitHub dan mendeploy-nya langsung secara live ke GitHub Pages dengan URL kustom.
Pelajari Langsung: W3Schools Git Tutorial GitHub Skills Interactive MDN Git & GitHub
05
FASE 5 • INTEGRASI REST API & STATE SISI KLIEN

Integrasi REST API & State Sisi Klien

Estimasi: 3–4 Minggu
Mengapa Topik Ini Penting?
Inilah titik temu yang menghubungkan Frontend dengan Backend REST API yang dipelajari pada silabus BPROTIC Web Track (Minggu 7–9) dan Mobile Track (Minggu 6–8). Di fase ini, kamu belajar cara merequest data dari server, menampilkan data secara dinamis, mengelola status loading spinner dan penanganan error, serta menyimpan preferensi pengguna di LocalStorage browser.
Topik & Keterampilan Kunci:
Format JSON (JSON.parse & JSON.stringify) Fetch API & HTTP Methods (GET, POST, PUT, DELETE) Request Headers (Content-Type & Bearer Token) UI State Handling (Loading Spinner & Error Boundaries) Web Storage API (localStorage & sessionStorage) Fondasi Lanjut Framework (React / Next.js)
Milestone Proyek Mandiri: Membangun Dashboard Katalog Produk yang mengonsumsi REST API Laravel BPROTIC, lengkap dengan pagination, filter kategori, modal formulir tambah data, dan bookmark LocalStorage.
Pelajari Langsung: W3Schools Fetch API W3Schools Web Storage MDN Panduan Fetch API
Profil Spesialisasi Karir

Backend Web Developer

Bertanggung jawab merancang arsitektur server-side, memodelkan basis data relasional yang efisien, mengamankan autentikasi & otorisasi, menjalankan logika bisnis kritis, serta menyediakan endpoint RESTful API terstandar yang siap dikonsumsi oleh aplikasi Web maupun Mobile.

Teknologi & Toolkit Kunci:
PHP 8.x Modern MySQL / MariaDB PDO & Prepared Stmt OOP & Pola MVC Laravel 11 REST API Postman & Laragon
Fokus: Server Architecture, Database & RESTful APIs
01
FASE 1 • FONDASI JARINGAN & SERVER

Cara Kerja Internet, Server & Arsitektur Client-Server

Estimasi: Minggu 1
Mengapa Topik Ini Penting?
Backend bertugas memproses data di balik layar. Tanpa memahami bagaimana browser mengirim permintaan HTTP, cara DNS menerjemahkan domain ke IP address, dan bagaimana Web Server (Apache) mengeksekusi berkas, seorang developer akan kesulitan saat menghadapi masalah koneksi atau error konfigurasi server.
Topik & Keterampilan Kunci:
Arsitektur Client-Server Protokol HTTP vs HTTPS DNS & Domain Resolution IP Address & Port (80, 443, 3306) Web Server Apache di Laragon Siklus Request & Response
Praktikum Silabus BPROTIC: Diterapkan pada Pertemuan 1 (Recap Setup & Dasar PHP) — Instalasi stack Laragon, virtual host .test, direktori root www, dan eksekusi server lokal.
Pelajari Langsung: roadmap.sh/backend W3Schools HTTP & Servers PHP.net Built-in Server
02
FASE 2 • BAHASA PEMROGRAMAN CORE

Fondasi Bahasa Pemrograman Backend (PHP 8.x)

Estimasi: Minggu 1 & 2
Mengapa Topik Ini Penting?
PHP mengeksekusi logika di sisi server sebelum data dikirimkan sebagai HTML/JSON ke browser. Memahami eksekusi server-side, kontrol logika percabangan, pengolahan array asosiatif (dasar struktur data JSON), serta teknik sanitasi input formulir HTML via superglobal $_POST wajib dikuasai untuk mencegah celah keamanan seperti Cross-Site Scripting (XSS).
Topik & Keterampilan Kunci:
Sintaks Inti & Variabel PHP 8.x Tipe Data Skalar & Type Hinting Alur Percabangan (if-else, match) Perulangan & Array Multidimensi Superglobal ($_POST, $_GET, $_SERVER) Sanitasi Form & htmlspecialchars
Praktikum Silabus BPROTIC: Diterapkan pada Pertemuan 1 & 2 (Logic, Form Handling & Database) — Mengirim data formulir registrasi, validasi server-side, dan sanitasi input.
Pelajari Langsung: W3Schools PHP Tutorial W3Schools PHP Form Handling PHP.net Language Reference
03
FASE 3 • PERSISTENCE & DATABASE

Basis Data Relasional & SQL (MySQL / MariaDB)

Estimasi: Minggu 2 & 3
Mengapa Topik Ini Penting?
Aplikasi backend membutuhkan penyimpanan data terstruktur dan persisten. Menguasai sintaks SQL memungkinkan manipulasi jutaan data dengan cepat. Yang paling krusial, developer wajib menguasai PHP Data Objects (PDO) dengan Prepared Statements guna menutup celah keamanan paling mematikan: SQL Injection.
Topik & Keterampilan Kunci:
Perancangan Skema Tabel RDBMS Primary Key, Foreign Key & Indexing Query DDL (CREATE, ALTER, DROP) Query DML CRUD (SELECT, INSERT, UPDATE, DELETE) Relasi Antar Tabel (INNER & LEFT JOIN) PHP PDO & Prepared Statements
Praktikum Silabus BPROTIC: Diterapkan pada Pertemuan 2 & 3 (CRUD PHP & MySQL) — Membangun aplikasi CRUD interaktif menggunakan koneksi PDO aman di database Laragon.
Pelajari Langsung: W3Schools MySQL Tutorial W3Schools SQL Joins PHP.net PDO Manual
04
FASE 4 • SOFTWARE ARCHITECTURE

Arsitektur Software, OOP & Pola Desain MVC

Estimasi: Minggu 4
Mengapa Topik Ini Penting?
Menulis kode prosedural dalam satu berkas yang mencampur query SQL, logika bisnis, dan tag HTML (spaghetti code) akan menyulitkan pemeliharaan aplikasi. Pemrograman Berorientasi Objek (OOP) dan pola Model-View-Controller (MVC) membagi tugas ke modul-modul independen (Separation of Concerns), membuat kode modular, teruji, dan merupakan fondasi wajib sebelum masuk ke Laravel.
Topik & Keterampilan Kunci:
Class, Object, Property & Method Constructor (__construct) & Visibility Pilar OOP: Encapsulation & Inheritance Model (Akses Data & Business Logic) View (Visual Rendering UI) Controller (Traffic & Request Handler)
Praktikum Silabus BPROTIC: Diterapkan pada Pertemuan 4 (OOP & MVC Dasar) — Refactoring aplikasi dari prosedural menjadi berorientasi objek dengan struktur folder terpisah: app/models, app/views, dan app/controllers.
Pelajari Langsung: W3Schools PHP OOP PHP.net OOP Manual roadmap.sh Architecture
05
FASE 5 • INDUSTRY & API READY

Framework Modern & RESTful API (Laravel Ecosystem)

Estimasi: Minggu 5 s/d 10
Mengapa Topik Ini Penting?
Di industri modern, backend menyajikan RESTful API dengan payload format JSON yang dikonsumsi aplikasi Mobile (seperti React Native / Expo di BPROTIC Mobile Track) maupun Web SPA. Laravel menyediakan ekosistem terlengkap: migrasi database otomatis, Eloquent ORM intuitif, API Resource transformer, serta otentikasi token yang aman.
Topik & Keterampilan Kunci:
Composer & Struktur Proyek Laravel Routing API (routes/api.php) Database Migration & Seeders Eloquent ORM & Relasi Data RESTful API JSON Responses (200, 201, 404, 500) API Testing dengan Postman Validasi Request & Token Auth Integrasi ke React Native Mobile
Praktikum Silabus BPROTIC: Diterapkan pada Pertemuan 5 hingga 10 — Mulai dari setup Laravel, Eloquent CRUD, pembuatan endpoint RESTful API JSON lengkap, pengujian payload di Postman, hingga dikonsumsi secara real-time oleh aplikasi Mobile Expo di pertemuan 6–10.
Pelajari Langsung: Laravel Docs Official Laravel Eloquent ORM Laravel API Resources roadmap.sh/backend #APIs

Fullstack Web Developer

01
MILESTONE 1 • CLIENT-SIDE FOUNDATIONS

Fondasi Client-Side (Frontend Core & Modern UI)

Estimasi: 2 Minggu
Mengapa Milestone Ini Penting?
Aplikasi fullstack yang tangguh memerlukan pintu gerbang antarmuka yang ramah pengguna. Menguasai HTML5 semantik, CSS Flexbox & Grid, serta Bootstrap 5 memungkinkan developer membangun tampilan antarmuka yang cepat di-render browser, responsif di semua resolusi, dan siap menerima aliran data dinamis melalui manipulasi DOM JavaScript.
Topik & Keterampilan Kunci:
HTML5 Semantik & Form Controls CSS Flexbox, Grid & Media Queries Bootstrap 5 Grid System & Interactive Modals JavaScript ES6+ (let/const, Arrow Functions) Array Methods (map, filter, find, reduce) Manipulasi DOM & Event Listeners
Milestone Proyek Mandiri: Membangun Dashboard Interaktif Responsif dengan form input dinamis, kalkulasi otomatis di sisi klien, dan mock data array JavaScript.
Pelajari Langsung: roadmap.sh/full-stack #Frontend W3Schools Frontend Track MDN Frontend Guide
02
MILESTONE 2 • SERVER-SIDE & DATA PERSISTENCE

Server-Side, Basis Data Relasional & Pola MVC

Estimasi: 2–3 Minggu
Mengapa Milestone Ini Penting?
Integritas data dan logika bisnis hanya bisa dijamin secara mutlak di sisi server. Mempelajari eksekusi PHP 8 modern, perancangan skema database MySQL yang ternormalisasi, serta PHP PDO Prepared Statements menjamin sistem kebal dari ancaman injeksi data. Ditambah pola MVC, aplikasi menjadi modular dan siap ditingkatkan skalanya.
Topik & Keterampilan Kunci:
PHP 8.x Sintaks, Functions & Type Hinting Desain Relasi MySQL (1-to-1, 1-to-Many, Many-to-Many) PHP PDO & Prepared Statements anti SQL Injection Pemrograman Berorientasi Objek (Class, Object, Inheritance) Pemisahan Arsitektur MVC (Model, View, Controller) Session Management & Password Hashing (bcrypt)
Sinkronisasi Silabus BPROTIC: Langsung dipraktikkan pada Web Track Pertemuan 1 s/d 4 — Mulai dari dasar PHP, koneksi PDO MySQL, CRUD data aman, hingga pemisahan struktur folder MVC mandiri.
Pelajari Langsung: W3Schools PHP & MySQL PHP.net PDO Security roadmap.sh/backend #Databases
03
MILESTONE 3 • FULLSTACK API BRIDGE & AUTHENTICATION

Fullstack API Bridge & Autentikasi Token

Estimasi: 2 Minggu
Mengapa Milestone Ini Penting?
Inilah esensi sejati dari seorang Fullstack Developer: menghubungkan dua dunia (Client dan Server). Di milestone ini, kamu meruntuhkan batasan monolitik tradisional dengan membangun komunikasi RESTful API berbasis JSON yang aman menggunakan token (Bearer Token / Laravel Sanctum), mengonfigurasi header CORS, serta mengelola status asinkron (loading, success, error) di sisi antarmuka.
Topik & Keterampilan Kunci:
Standar REST API & HTTP Status Codes (200, 201, 401, 422, 500) Pertukaran Data JSON & Kontrak Payload Token Authentication (Bearer Token / Laravel Sanctum) Cross-Origin Resource Sharing (CORS) & Headers Fetch API Asinkron dengan Authorization Header API Testing & Debugging dengan Postman
Milestone Proyek Mandiri: Membangun Aplikasi Decoupled Task Manager: Antarmuka Bootstrap melakukan login, menyimpan token di LocalStorage, dan mengonsumsi REST API Laravel secara asinkron dengan feedback Toast & Spinner.
Pelajari Langsung: Laravel Sanctum Token Auth MDN CORS Explained W3Schools Fetch with Auth
04
MILESTONE 4 • MODERN FULLSTACK ARCHITECTURE

Arsitektur Fullstack Modern (Eloquent ORM & Multi-Client Ready)

Estimasi: 2–3 Minggu
Mengapa Milestone Ini Penting?
Sistem fullstack kelas produksi harus scalable dan sanggup melayani berbagai klien sekaligus: Web Browser desktop, tablet, hingga aplikasi mobile native (seperti React Native Expo di Silabus BPROTIC Mobile Track). Menguasai Eloquent ORM relasional, API Resources transformer, dan caching sisi klien memastikan performa tinggi dan data yang konsisten.
Topik & Keterampilan Kunci:
Laravel Eloquent Relasional (hasMany, belongsTo, belongsToMany) Migrasi Database, Seeders & Model Factories Eloquent API Resources (Transformasi & Proteksi Data) Query Filtering, Searching & Server-Side Pagination Multi-Client Backend (Web Client & Mobile Expo Consumer) Client-Side State Caching & Synchronous Optimistic UI
Sinkronisasi Silabus BPROTIC: Diterapkan pada Web Track Minggu 5–9 dan dikonsumsi langsung oleh Mobile Track Minggu 6–9 — Arsitektur API Laravel yang sama melayani halaman web sekaligus aplikasi Android React Native.
Pelajari Langsung: Laravel Eloquent Relations Eloquent API Resources roadmap.sh/full-stack #Architecture
05
MILESTONE 5 • DEPLOYMENT, GIT WORKFLOW & CI/CD

Version Control, Deployment Cloud & Production Readiness

Estimasi: 1–2 Minggu
Mengapa Milestone Ini Penting?
Kode yang hebat tidak ada gunanya jika hanya tersimpan di localhost laptop developer. Fullstack engineer bertanggung jawab mengawal kode ke server produksi: mengamankan kredensial database via .env, memasang sertifikat SSL HTTPS, mengotomatisasi rilis dengan GitHub Actions, serta memonitor error log secara real-time.
Topik & Keterampilan Kunci:
Git Branching Workflow (main, develop, feature branches) GitHub Collaboration & Pull Request Code Review Manajemen Variabel Lingkungan (.env Secrets Security) Cloud Deployment (cPanel Hosting / VPS Ubuntu / Railway / Render) Pengamanan SSL/TLS Certificate (HTTPS Let's Encrypt) Dasar CI/CD Otomatisasi (GitHub Actions Deploy) Error Logging, Health Check & Performance Monitoring
Milestone Proyek Mandiri: Mempublikasikan Aplikasi Fullstack terintegrasi secara live ke server Cloud/Hosting publik dengan HTTPS aktif, database MySQL cloud terhubung, dan repository GitHub publik dengan dokumentasi README profesional.
Pelajari Langsung: Laravel Deployment Guide roadmap.sh/devops W3Schools Git & CI/CD
